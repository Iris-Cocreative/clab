Light and dark

The site ships in both. Light is the default; a visitor's operating system preference is honoured until they choose explicitly, and the choice is then remembered. Use the switch in the bar above to check any part of these guidelines in the other mode.

Author once. Every colour token flips between the two modes, so a page is built without thinking about theme at all. There is no separate dark stylesheet and no page needs a dark-mode override. A theme script runs before first paint, so the correct mode is painted immediately rather than flashing.

Logo

The mandala is the identity and the map. It is a fifteen-stop hue wheel held in a lattice, and it carries the full spectrum so nothing else has to. This is why there is no rainbow type anywhere in these guidelines, and why the palette below is as quiet as it is.

Two files, one mark

The lattice is drawn dark for light grounds and light for dark grounds. The right one is chosen automatically by the theme.

Clear space and minimum size

Clear space on all four sides is half the width of the mark. Nothing enters that field.

ContextSize
Hero and the movements centrepiece200 to 440px
Navigation30px
Footer28px
Absolute minimum24px, and only with the minimalist variant when it lands

Do

  • Let the theme pick the file.
  • Keep it circular and unrotated, except for the slow turn it is given in the hero and the movements.
  • Respect the clear space.

Do not

  • Recolour, flatten to one colour, or add a gradient.
  • Add a shadow, outline or glow.
  • Stretch, crop, or set it at an angle.
  • Place it over a busy photograph without a calm area behind it.

Colour

One neutral scale, one accent, and the five movement hues. That is the whole palette. The spectrum belongs to the logo and to the five movements; it appears nowhere else, so those two can carry it without competition.

The earlier palette had two accent families and three variants of each. Clay and sage both competed with the logo, and with the movements, and with each other. Collapsing to a single brass accent is what lets the mandala read as the only colourful thing on the page.

Typography

Two families. Cormorant Garamond carries everything editorial. DM Mono carries everything functional. The contrast between a very large, very light serif and a very small, widely tracked mono is what makes the page feel spacious rather than merely tidy.

FamilyCarriesNever
Cormorant GaramondHeadings, body copy, quotes, movement names, offering names, statistics.Navigation, buttons, labels, captions.
DM MonoNavigation, eyebrows, buttons, captions, fine print, numbers in the interface.Anything longer than a few words.
Cormorant has a small x-height, so its reading size runs large. Body sits at 19px, which reads about like 16px of a normal face, with a 1.75 line height. Never set it below 17px where copy has to be read. This is the one rule that keeps an elegant face from becoming an unreadable one.

The italic accent

Cormorant's italic is where its character lives. It marks the one word in a heading that should sing, set in the accent colour with .em. One per heading, never more.

A Growing International Community

Do

  • Set display type at weight 300 with tracking -0.02em.
  • Use the italic accent on one word per heading.
  • Keep body measure at or under 42rem.
  • Set every label in DM Mono, uppercase, widely tracked.

Do not

  • Colour type with the movement hues. The logo carries the spectrum.
  • Set Cormorant below 17px for anything read.
  • Set DM Mono in sentences or paragraphs.
  • Introduce a third family.

The five movements module

The homepage centrepiece. The section runs several screens tall, the stage sticks, and scroll position drives which movement is active. The mandala is the map: the logo sits at the centre and the five movements arrange around it, joined by a spoke to whichever is active. The rail on the left doubles as a scroll-progress indicator and as navigation. Nodes and rail items are keyboard reachable, and below 56rem the whole thing collapses to a plain stacked list with no scroll hijacking.

See it working on the homepage.

Motion

Slow and organic. Nothing should feel snappy: the subject is a long-arc practice and the motion agrees with it. One easing curve across the whole site.

Reduced motion is honoured everywhere. Under prefers-reduced-motion: reduce all transitions collapse, the mandala stops turning, smooth scrolling is off, revealed sections start visible, and the movements module drops its scroll tie and becomes a plain list.

Accessibility

RuleHow it is held
Text contrastWCAG AA or better in both light and dark. Every pair is measured and published above.
FocusOne visible ring in the accent colour, never removed. A skip link is the first tab stop on every page.
Colour aloneNever the only carrier of meaning. The active movement is marked by size, position, the spoke, the ghosted numeral and the rail bar, not only by hue.
The movements moduleNodes and rail items are buttons with role="tab", reachable by keyboard, arrow-navigable, and the detail panel is a live region.
Scroll hijackingNone. The module is driven by ordinary scroll position and can be skipped past at any speed.
HeadingsOne h1 per page, no levels skipped.
ImagesMeaningful images take alt text. The mandala is decorative and takes alt="".

Performance

One rule here, and it is not obvious, so it is written down.

The mandala is always an <img>, never an inline <svg><use>. The artwork is 76 paths. Inlined and placed inside the sticky movements module, Chrome re-rasterises the whole thing on every scroll frame instead of caching it, which is enough to stop the page responding altogether. As an <img> it is decoded once and cached, and scrolling stays smooth. The cost is carrying two files so the lattice can invert with the theme, which is a good trade.

Two smaller consequences of the same principle: the rotating marks carry will-change: transform so the turn stays on the compositor, and the active movement node uses a second circle for its halo rather than an SVG drop-shadow filter, because that element changes on every scroll tick and filters are re-evaluated each time.

Using this

These guidelines are not a picture of the design system. They are the design system, rendered.

Adding a page

Link the two stylesheets, copy the theme script, navigation and footer from an existing page, and build the body from the components above. A new page should not need a single new colour or spacing value, and should not need any dark-mode work at all. If it does need a new value, that value belongs in tokens.css and in these guidelines before it is used.
