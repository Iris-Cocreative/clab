Logo

The mandala is the identity and the map. It is a fifteen-stop hue wheel held in a lattice, and it carries the full spectrum so nothing else on the site has to. This is why there is no rainbow type anywhere in these guidelines.

Variants

Two variants, chosen by the surface behind them. The lattice lines are white in one and filled in the other, so each holds its detail against its intended ground.

On light · clab-mandala-on-light.svg
On dark · clab-mandala-on-dark.svg
Both variants stay alive. The lattice version is for large use, where the detail is legible and doing work. A minimalist version is for small use, where the lattice fills in and the mark stops reading. The minimalist variant is still being tightened so the C reads clearly at small sizes, and will be added here when it lands.

Clear space and minimum size

Clear space on all four sides is half the width of the mark. Nothing enters that field: no type, no rule, no photograph edge.

ContextSizeVariant
Section centrepiece120 to 190pxLattice
Hero mark96 to 148pxLattice
Navigation34pxLattice, minimalist when ready
Favicon32px and belowMinimalist
Absolute minimum24pxMinimalist only

Do

  • Use the variant that matches the surface behind it.
  • Keep the mark circular and unrotated.
  • Let it sit alone, with its clear space respected.

Do not

  • Recolour, flatten to one colour, or add a gradient.
  • Add a drop shadow, outline or glow.
  • Place it on a busy photograph without a calm area behind it.
  • Stretch, crop, or set it at an angle.

The decorative and text split is the single most important rule on this page. Clay at its natural value measures 3.39:1 against cream, which fails WCAG AA for body text and for a 13px button label. The earlier homepage preview set buttons, links and section labels in it. Clay Deep exists so the colour reads the same and the text passes. When in doubt, use the value whose name ends in -deep.

Typography

Fraunces and Montserrat, agreed 24 April 2026. Fraunces is a variable serif with optical sizing, so it holds warmth at display sizes without turning decorative. Montserrat carries everything a person reads at length or acts on.

A note on the name. Earlier records of that conversation say "Frances." The typeface is Fraunces, a Google font. The two are easy to confuse and only one of them exists.

Division of labour

FamilyCarriesNever
Fraunces Headings, pull quotes, movement names, offering names, stat numbers, the wordmark. Body copy, buttons, form fields, navigation.
Montserrat Body copy, navigation, buttons, labels, form fields, captions, fine print. Anything above 26px.

Scale

A major third, roughly 1.25, fluid where it earns it. Body sits at 17px: large enough to read comfortably, small enough that a 720px measure lands near the 65 to 75 character ideal.

Rules

Do

  • Set headings in Fraunces 500 with letter-spacing -0.01em.
  • Use Fraunces italic for ledes, quotes and movement names.
  • Keep body measure at or under 720px.
  • Set eyebrows uppercase at 0.14em tracking.

Do not

  • Colour type with the spectrum. The logo carries it.
  • Use Fraunces below 18px, where its detail closes up.
  • Set body copy in the display face.
  • Introduce a third family, including for code or numerals.

Space and rhythm

A four pixel base, ten steps. Every margin, padding and gap on the site is one of these. This is the fix for the unresolved vertical rhythm in earlier rounds, where blocks opened into three or four hundred pixels of dead air because spacing was chosen fresh in each section.

Section rhythm

TokenValueUsed for
--section-y72px to 120px, fluidVertical padding on every section. One value, so the page breathes at a single interval.
--section-y-tight48px to 72px, fluidThe quote band and other interludes that should not feel like full sections.
Sections do not set their own padding. They inherit --section-y. If a section needs more air, the answer is a .section-head or an added element, not a custom margin. This is what keeps the rhythm honest.

Layout

Three widths, no more.

ClassWidthFor
.wrap720pxBody copy. The default. Lands near 68 characters at 17px.
.wrap--content1080pxCard grids, section headers, quote pairs, the footer.
.wrap--wide1200pxThe navigation bar only.

Gutters are 28px, dropping to 20px below 640px. Breakpoints are set in rem and chosen where the content actually breaks, not at device widths: 52rem for the navigation, 46rem for three-column grids, 40rem for the movement journey, 34rem for two-column grids.

Motion

Slow and organic. Nothing here should feel snappy. The subject is a long-arc practice and the motion agrees with it.

TokenDurationUsed for
--dur-fast160msColour changes on hover.
--dur240msThe default. Buttons, links, cards, the nav panel.
--dur-slow600msLarger state changes.
--dur-reveal900msSections easing in on scroll.
--easecubic-bezier(0.22, 0.61, 0.36, 1)Everything. One curve across the site.
Reduced motion is honoured everywhere. Under prefers-reduced-motion: reduce all transitions collapse to nothing, smooth scrolling is turned off, and revealed sections start visible. Motion is never the only way something is communicated.

Accessibility

The standard this site holds, so it stays true as pages are added.

RuleHow it is held
Text contrastWCAG AA or better, everywhere. Every colour pair in these guidelines is measured and published above.
FocusOne visible focus ring, Clay Deep on light and Clay Soft on dark, never removed. First tab stop on every page is a skip link.
Colour aloneNever the only carrier of meaning. Movement dots are labelled; tab state is set with aria-selected, not only with fill.
HeadingsOne h1 per page, no levels skipped.
ImagesMeaningful images take alt text. Decorative marks take alt="".
MotionAll of it optional, see above.
TargetsInteractive elements are at least 44px tall in their tap area.

Using this

These guidelines are not a picture of the design system. They are the design system, rendered.

FileWhat it holds
system/tokens.cssEvery colour, size, space, radius and duration on the site. The only file with raw values in it.
system/base.cssElements and components, built entirely from tokens.
assets/js/site.jsThree behaviours: mobile navigation, the offerings filter, the scroll reveal.
assets/img/Logo variants.

Adding a page

Link the two stylesheets, copy the navigation and footer from an existing page, and build the body from the components above. A new page should not need a single new colour or spacing value. If it does, that value belongs in tokens.css and in these guidelines before it is used.
